## Native Android dependency audit

The pub inventory is not a complete native Android attribution report. Android
Gradle Plugin, AndroidX, Kotlin and plugin-transitive Maven dependencies are
resolved separately. Inspect the actual release graph before distribution:

```sh
cd android
./gradlew :app:dependencies --configuration releaseRuntimeClasspath
```

Use that resolved graph and upstream POM/LICENSE/NOTICE texts to finish binary
attribution review. Do not assign a blanket license to all native dependencies.
Android System WebView and the independently configured Brew Guide deployment
are separate software/services; this repository does not relicense them.
